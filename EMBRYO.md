# Embryo Board IDE

Embryo Board IDE is Embryo-Zero's fork of [arduino-ide](https://github.com/arduino/arduino-ide) (f467a6a, commit f467a6a). It does Arduino-style board programming.

- Our changes live on the `embryo` branch. The original license files (LICENSE.txt) are unchanged.
- Legal notes: LEGAL.md. Dated list of our changes: CHANGES-EMBRYO.md.
